## Image Specifications
- **Format:** PNG
- **Max Width:** 800px
- **Aspect Ratio:** 16:9 or 4:3
- **File Size:** < 500KB per image
- **Style:** Dark theme matching the profile aesthetic

## Tips
- Capture full-page screenshots for context
- Use clean, uncluttered views
- Avoid showing personal data in demos
- Crop to remove browser chrome
